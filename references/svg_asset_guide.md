# SVG 素材制作指南 (SVG Asset Guide)

本指南基于 `adaptive_learning_flywheel.svg` 的实战经验，约定了自动化演示中 SVG 素材的设计风格、应用场景及动效规范，旨在产出具有“高科技感”和“动态叙事力”的视觉资产。

---

## 1. 核心视觉风格 (Visual Style)

为了确保 PPT 整体的电影感，SVG 素材应遵循 **"玻璃拟态 (Glassmorphism)"** 与 **"深邃科技 (Deep Tech)"** 风格。

### 1.1 色彩规范
- **背景 (Background)**：`#020617` (深靛蓝，近乎黑)
- **主色 (Primary)**：`#6366f1` (靛青，用于核心流线与品牌标识)
- **辅助色**：
    - 强调色：`#a855f7` (紫色，用于关键动作/流程)
    - 科技青：`#06b6d4` (青色，用于工具/数据块)
    - 生机绿：`#10b981` (绿色，用于增长/成功节点)
- **容器样式**：
    - 背景：`rgba(255, 255, 255, 0.03)`
    - 边框：`rgba(255, 255, 255, 0.12)` (1.2px 细线)

### 1.2 字体规范
- **主标题**：`Plus Jakarta Sans` (粗体/800)，确保在缩放时依然清晰。
- **正文/说明**：系统默认无衬线字体，字号不小于 `14px`。

---

## 2. 场景与样式映射 (Scenarios & Layouts)

| 场景 | 推荐布局 | 视觉特征 |
| :--- | :--- | :--- |
| **闭环/飞轮 (Flywheel)** | 环形布局 + 中心节点 | 使用 `flywheel-ring` 虚线圆环作为背景装饰，强调持续进化。 |
| **业务流 (Workflow)** | 线性/网格布局 | 使用 `box-rect` (20px 圆角) 承载步骤，配合 Lucide 风格线性图标。 |
| **系统架构 (Architecture)** | 层级堆叠布局 | 下层使用低透明度色块，上层使用高对比度描边块。 |

---

## 3. SVG 动效规范 (Animation Patterns)

动效不应仅为了华丽，而应服务于**“信息传递的先后顺序”**。

### 3.1 核心动效库
- **绘制线 (lineDraw)**：用于表现数据流向。
    - *原理*：操作 `stroke-dashoffset`。
    - *建议*：12s 为一个大周期，1s 完成绘制，后续保持 20% 透明度常驻。
- **节点脉冲 (nodePulse)**：用于吸引观众注意力。
    - *原理*：结合 `scale(1.05)` 与 `brightness(1.3)`。
    - *触发*：在线条绘制到达该节点时立即触发脉冲。
- **中心闪烁 (avaFlash)**：用于体现“智能体”在思考。
    - *效果*：柔和的 `drop-shadow` 呼吸感。
- **背景旋转 (rotateFlywheel)**：用于营造空间深度感。
    - *效果*：极慢速 (20s+) 的虚线圆环旋转。

---

## 4. 制作最佳实践

1.  **transform-box: fill-box**：在定义 SVG 动画时必须添加，确保变换中心在元素自身中心而非 SVG 原点。
2.  **动画延迟 (Animation Delay)**：利用 `animation-delay` 实现步骤间的先后衔接（例如：Line 1 完成 -> Node 2 脉冲 -> Line 2 开始）。
3.  **符号复用 (<use>)**：图标应定义在 `<defs>` 中，通过 `<use>` 引用，减少代码冗余并保持风格统一。

## 5. 快速复用模板
```xml
<!-- 一个标准的 AVA 风格容器 -->
<g transform="translate(x, y)">
  <rect x="-130" y="-50" width="260" height="100" rx="20" 
        style="fill: rgba(255,255,255,0.03); stroke: rgba(255,255,255,0.12); stroke-width: 1.2;" />
  <text class="label-main">核心步骤标题</text>
</g>
```
